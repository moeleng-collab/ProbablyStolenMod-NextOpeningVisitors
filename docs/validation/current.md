最终复验未出现编译警告，DLL 构建、本地安装和官方扫描成功。`run_scan.py` 调用游戏自己的 `ModScanner.Scan()` 扫描最新构建 DLL；上述结果只代表该次程序集未被扫描器拒绝，不证明算法、UI、电话、存档或兼容性正确。

1.7.0 的“夜猫子”通过原生开局特性接口注册，成本 2 点；只在店门原生检查前补充耗尽的总次数，并以每个地点原生存档中的 `visits` 与 `lastVisitDay` 限制当晚重复访问。规则测试使用任意第三方地点 ID 验证动态集合、跨夜重置和未选特性不干预。用户已整体确认本次功能测试无问题，但未逐项说明地点卡片、店门提示、读档或第三方 Mod 组合场景。

鉴定详情的旧 `TreeNodeRender` 版本已在日志中确认文本生成并激活，但用户实测画面不可见；随后自行创建 `Image` 与 `TextMeshProUGUI` 的版本只显示黑框，没有文字。按 `AppraisalAssistant 1.0.7` 的界面路径改用游戏原生 `CustomUIManager.Window(..., "overlay")`、`CustomUIBuilder.AddLabel()` 和语言字体后，用户已确认库存香烟的鉴定窗口可见。该结果只覆盖香烟窗口基本显示，其他物品、价值和交互仍待验收。

用户随后报告改造体到店没有提醒，截图中交易界面已打开但没有身份提示。对应运行日志确认 1.6.0 正常初始化，且没有到店提醒刷新异常。1.6.1 将到店提醒从同类旧 `TreeNodeRender` 面板改为已验证基本可见的原生窗口，并增加顾客身份与 UI 就绪状态日志；真实改造体到店提醒仍待复验，不能仅凭编译和扫描认定修复已在游戏中生效。最新候选为每次顾客实例记录手动关闭状态，已覆盖关闭后不重开、UI 就绪切换、新顾客和旧回调隔离的纯规则测试；真实关闭按钮行为仍待复验。

武器定制高亮已补充 `GUNSMITH` 订单匹配、固定口径检查和机器输出口中可见自有物品的补扫；定制与改造订单还会按必选及奖励属性要求筛选相关配件，覆盖百分比／固定值方向、尺寸和消音器等级。最新候选会用当前订单武器动态跳过已达成条件，同属性存在未完成更高奖励档位时继续显示。实际动态撤框仍待复验。

荧光莓品质标志已按唯一物品 ID 接入放大镜鉴定记录和 `PlayerStore.ModData()` 存档，四种请求图标、未鉴定隐藏、重复鉴定更新及序列化通过纯规则测试。用户已确认初版图标位置正确，本次按要求放大 2 个 UI 像素。放大后尺寸、拖拽显示、禁用清理及读档恢复尚未游戏内验收。

F8 功能列表现有 13 项独立开关并随存档保存，默认全部开启，支持单项与全部切换、子功能独立启停和既有 UI 清理；预约去重与电话文案按用户要求固定开启。早期日志分别证实新增权限导致 Mod 未加载、过早注册导致 `InputActionManager.current` 空引用，以及场景重进缺少第二次 F8 注册。最新候选会在每个场景的按键管理器中重新加入持久 F8 处理器，在荧光莓功能开启时通过 `PlayerStore.FindAllItem(false)` 重注册现有物品，并将电话冷却单项切换直接接入按钮启停和点击拦截。用户已确认场景重进与荧光莓开关恢复修复生效，以及冷却按钮关闭后消失；重新勾选冷却开关时的按钮恢复也已补建，仍需复验。扫描保持 `Capabilities: <none>`、0 拒绝和 0 异常。1.6.2 发布后，鉴定详情、到店提醒窗口标题与正文、以及 F8 功能开关文案已按现有 11 语表补全，纯规则测试现为 2730 条断言；编译、本地安装和扫描均完成。这批本地化尚未随 Workshop 更新发布，游戏内 11 语布局仍未验收。

2026-11-17 的 1.6.3 本地热修复针对旧日志中连续 216 次 `Could not refresh item highlights` 空引用。旧日志只保存异常消息，无法从堆栈证明唯一触发点；代码确认无顾客时进入的 `HideAll()` 仍会无条件读取 `UISettings.current.gridSize`，并存在其他未初始化的拖拽／渲染节点访问。修复后 UI 未就绪时边框隐藏，相关节点做空值保护；相同堆栈的连续异常只记录一次完整异常，恢复时报告抑制次数。规则测试 2730 条断言通过，编译、本地安装和官方扫描通过（354 个方法、无权限、0 硬标记、0 发现）。构建与安装 DLL 均为 256000 字节，SHA-256 为 `b755531db1f2abd4a4101fd8349d71580e92902f080767bdd0f03b17e21a5372`；项目与安装清单 SHA-256 均为 `6d5d82436631bc6a28f3bf83f062a6e2a85eb065addb64fd944ba948762e6400`。实际初始化、原报错场景不再刷屏及三类高亮功能仍待游戏内验收；不能据此认定与早先原生闪退有关或无关。

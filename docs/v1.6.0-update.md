# v1.6.0 更新规格

- 目标游戏：《Probably Stolen》`0.46D`
- 状态：1034 条纯规则断言、262 个方法的官方扫描及无警告构建已通过；用户已确认库存香烟鉴定窗口可见，其余真实 UI、存档和 Mod 组合仍需游戏内验收

## 1. 顾客需求、治安盘查与武器订单高亮

### 1.1 触发与颜色

- 当前顾客为 `BUY` 或 `SELLNBUY` 时，高亮 `IsClientBuyingThisItem(item, true)` 接受的物品。
- 当前顾客意图为 `INSPECTION` 时，只高亮按 `ContrabandHelper.InspectItem(item)` 同等只读标签规则判定会被检查的物品。
- 绿色：普通需求；黄色：赃物；红色：违禁品。双标签时红色优先。
- 高亮仅新增不接收鼠标事件的边框，不移动物品、不成交、不调用随机盘查或结算。

### 1.2 递归与边界

- 需求模式扫描玩家主库存、前后店库存、柜台、展柜、集市、隐藏库存、已售库存及物品内部容器。
- 顾客需求模式遇到当前锁住的容器时停止向内部递归；带 `ITEM_BEHIND_LOCK_TAG` 的物品不高亮。
- 盘查包含原版实际检查的垃圾桶，懒惰治安官按原版规则跳过；阻查容器停止递归，合法物品和未打开的隐藏库存不扫描。
- 外层容器显示所有可见子物品中的最高风险颜色，红 > 黄 > 绿 > 无。
- 边框跟随旋转与拖拽节点，厚度为 `max(1, gridSize / 16)`；每约 0.25 秒刷新并在物品销毁、客户切换和禁用时清理。

### 1.3 武器定制与动态配件

- `GUNSMITH` 普通定制订单高亮口径合适的可定制基础武器，维修订单不标无关武器；同时补扫机器输出口中的可见自有物品。
- 定制与改造订单按必选、奖励条件筛选配件，覆盖火力、风格、可靠性、后坐、人机和精度的百分比／固定值方向，以及尺寸和消音器等级。
- 每次刷新通过 `GunOrderData.ResolveOrderGun()` 和原生 `GunOrderRequirement.IsMet()` 跳过已达成条件；同属性存在更高未完成奖励档位时继续显示。

## 2. 放大镜自动鉴定与物品详情

- 鉴定服务中自动填入 `AppraisalHelper.GetCorrectBaseValue(item)` 的正整数真实估值，并同步原生默认值；不自动提交、结算或销毁物品。
- 免疫宁注射器、海明威香烟、食品券与肋明治显示真伪和具体赝品原因。
- 仿生机械手、肋明治、等离子燃料匣显示真实总价和逐项价值；拆解与原版结果不一致时只显示总价及详情不可用。
- 荧光莓显示正常、较小、发霉、未熟、干枯；未知组合不强行归类。
- 物品详情通过原生 `CustomUIManager.Window(..., "overlay")` 与 `CustomUIBuilder.AddLabel()` 显示。用户已确认库存香烟窗口可见，其他物品与交互待验收。

## 3. 改造体与通缉犯提醒

- 放大镜模式显示改造检测及可核实理由，没有可见线索时不虚构证据。
- 改造体或通缉犯到店时无需放大镜即显示身份、真名、改造等级与举报奖励。
- 只显示信息，不修改客户状态、不触发对峙、不派遣治安官。

## 4. 本地化、兼容与验收

- 新增提示接入游戏语言设置，鉴定详情使用中文及英文回退。
- 测试时停用 `ClientDemandHighlight` 与 `AppraisalAssistant`，避免重复边框、窗口及输入覆盖；不修改或分发第三方文件。
- 自动化覆盖颜色优先级、库存边界、武器与配件匹配、动态条件、鉴定公式、身份提醒和本地化。
- 当前结果为 1034 条断言、262 个方法扫描，`Refused: False`、`HardFlags: 0`、`Findings: 0`。
- 动态配件撤框、其他鉴定物品、完整交易、存档、11 语布局、Mod 组合及禁用重启用仍待实际游戏内验收。

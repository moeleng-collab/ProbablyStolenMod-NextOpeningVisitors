# 供货商与奥丁电话本地化

- 当前状态：源码已实现；游戏内专项验收未执行
- 目标游戏：《Probably Stolen》`0.46D`

## 行为规格

`LocHelper.GetLocalizedDialoguePhone()` 返回原版文本后，Mod 只改写已知的 21 个目标 key，统一表达“下一次开店”，使电话承诺与[访客调度](visitor-scheduling.md)的实际时序一致。

处理边界：

- 未知 key 保留原版返回值；
- 缺少订单数量参数时保留原版返回值；
- 非目标电话和冷却原文不改写；
- 中英文订单保留数量参数，不因替换丢失信息。

支持：`en`、`zh`、`ja`、`de`、`ru`、`fr`、`es`、`pl`、`ptBR`、`ko`、`it`。语言规范化忽略 `-` 与 `_`，中文区域代码归入 `zh`，葡萄牙语归入 `ptBR`，未知语言回退英文。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `src/PhoneDialogueTextPatch.cs` | 对目标电话本地化结果进行后置替换 |
| `src/PhoneDialogueTextRules.cs` | 21 个 key 的映射与参数化文案 |
| `src/ModLocalization.cs` | 公共语言规范化与回退 |

补丁不修改原版本地化资源文件。未知输入必须保持原文，避免把新游戏版本或其他 Mod 的电话误识别为供货商订单。

## 验证与验收

当前全局自动化结果见[验证记录](../validation/current.md)。

### 纯规则覆盖

- 21 个目标 key 在 11 种语言下均有非空替换；
- 中英文订单保留数量并采用下一次开店表述；
- `pt-BR`、`zh-Hans` 等别名规范化，未知语言回退英文；
- 缺少参数、非目标 key 和冷却原文保持原样。

这些断言不验证实际字体、气泡宽度、换行或对话与到访的真实组合。

### 游戏内专项验收

- [ ] 四种供货商和奥丁电话文案与实际下一次开店到访一致。
- [ ] 普通与免费订单的数量参数显示正确。
- [ ] 非目标电话、剧情 `wanted4` 和冷却文本保持原意。
- [ ] 11 种语言及未知语言回退在真实电话中可用。
- [ ] 常用分辨率和 UI 缩放下，中英文长文本无裁切、遮挡或错误换行。

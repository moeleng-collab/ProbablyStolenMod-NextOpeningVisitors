# F8 功能列表与独立开关

- 当前状态：源码已实现并通过纯规则、编译与官方扫描；真实窗口与逐项游戏内验收未执行
- 目标游戏：《Probably Stolen》`0.46D`

## 行为规格

在店内按 F8 直接打开本 Mod 的功能列表，再次按 F8 关闭。入口使用游戏原生 `InputActionManager` 按键事件系统，不占用 F9，也不依赖其他调试界面是否启用。窗口仅提供本 Mod 的功能开关，不提供原生调试面板入口。

列表使用原生 `CustomUIManager.Window(..., "overlay")`、滚动容器和 `AddToggle()`，分为“访客与电话”“预测与物品高亮”“鉴定与身份提醒”三组。全部 13 项默认开启，单项切换立即生效并提供全部开启／全部关闭按钮。功能列表本身不属于可关闭项，全部关闭后仍能按 F8 重新打开。

| 分组 | 独立功能 |
| --- | --- |
| 访客与电话 | 下一次开店优先到访、电话冷却一键清除、调查满值自动清除来电 |
| 预测与物品高亮 | 交易预测、夜间预测、顾客需求高亮、治安盘查高亮、武器定制／改造高亮 |
| 鉴定与身份提醒 | 自动真实估值、放大镜鉴定详情、荧光莓品质标志、放大镜改造人检测、改造体／通缉犯到店提醒 |

重复预约合并与下一次开店电话文案固定开启，不列入开关，旧存档中对应的已关闭 ID 也不会再停用它们。电话冷却单项切换会直接调用按钮启停并阻止点击处理，不再只修改设置值；重新勾选时会在当前电话界面立即补建按钮，已存在时不重复创建。

关闭功能只停止后续修改并清理对应 UI，不回滚已经发生的预约、文案、估值、现金、调查或存档变化。例如，关闭预约优先后不会恢复此前已调整的队列；关闭荧光莓标志不会删除鉴定记录；关闭自动清除来电会移除运行时服务、停止展示并阻止接受报价，但不会撤销已经完成的清除。

共用宿主的功能按子项判断：三类高亮分别独立；自动估值、鉴定详情、放大镜检测和到店提醒分别独立。关闭鉴定详情、放大镜检测或到店提醒时，已经打开的对应窗口会立即关闭。自动清除来电即使在电话对话打开后被禁用，接受报价也不会扣款或修改调查。

## 存档与故障回退

设置通过 `PlayerStore.ModData()` 的 `nextopeningvisitors.feature_settings.v1` 键随各存档保存。序列化只记录已关闭功能的稳定数字 ID；空数据、旧存档和未来新增功能默认开启。重复 ID、未知 ID、损坏数据和未知版本会被拒绝并恢复全部默认开启，同时记录警告，不改写其他 Mod 数据。

禁用整个 Mod 时，总开关先使全部功能判断失效，再关闭 F8 窗口、清理各功能宿主和 UI、退订事件。重新启用后按当前存档设置恢复。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `src/FeatureSettingsState.cs` | 13 项功能目录、默认值与确定性序列化 |
| `src/FeatureSettingsLocalization.cs` | 窗口标题、说明、分组、全部开关按钮与功能标签的 11 语文本；未知语言回退英文。这些表在 1.6.2 发布后于当前工作区补全，游戏内 11 语布局仍未验收 |
| `src/FeatureSettings.cs` | 总开关、单项切换、全部切换、存档读写和按功能启停 |
| `src/FeatureSettingsUI.cs` | F8 入口替换、原生滚动窗口、开关列表、全部切换和关闭清理 |
| 各功能源码 | 读取独立开关或接收启停调用，保持原有规则不变 |

F8 由 `FeatureSettingsInputHandler : EmptyActionHandler` 注册到原生 `InputActionManager`，只监听 `KeyCode.F8`，在按键帧切换列表并阻止后续原生动作处理器重复消费。只有 `InputActionManager.current` 已就绪时才创建处理器，避免 Mod 初始化过早导致注册空引用；每次读档应用设置时还会把持久处理器加入当前场景的按键管理器，回到主菜单再进游戏后也能恢复。注册成功和收到 F8 各有一条一次性诊断日志。处理器在禁用 Mod 时销毁，不直接引用 Unity 输入模块，不引用控制台程序集，也不需要新增权限。窗口复用鉴定详情的字体适配，避免引入额外程序集引用。

## 验证与验收

### 纯规则覆盖

- 13 项功能完整枚举且默认全部开启；
- 窗口标题、说明、分组、全部开关按钮及全部功能标签在 11 种语言下非空，未知语言回退英文；
- 单项关闭不影响其他项；
- 禁用 ID 稳定排序、空数据、存档往返、全部开启和全部关闭；
- 未知版本、未知 ID、重复 ID 和损坏数据拒绝。

这些测试不实例化 Unity 窗口，不证明真实 F8 输入、滚动、字体、各功能运行时清理或存档文件行为。

### 游戏内专项验收

- [ ] 按 F8 打开列表，再按 F8、Escape 和关闭按钮均能关闭；窗口不出现原生调试面板入口或相关描述。
- [ ] 三组共 13 项完整可见，滚动、中文字体、拖动和常用 UI 缩放正常。
- [ ] 11 种语言下窗口标题、分组、开关标签和按钮布局无裁切或遮挡。
- [ ] 每项单独关闭后对应行为停止，其他功能不受影响；重新开启后恢复。
- [ ] 鉴定详情、放大镜提示、到店提醒、高亮和荧光莓标志在关闭后立即清理。
- [ ] 自动清除来电关闭后不再呼出，打开中的报价也不会再扣款或清调查。
- [ ] 全部关闭后 F8 列表仍可打开，全部开启能恢复所有功能。
- [ ] 保存、退出和读档后设置按存档恢复，两个存档互不污染，禁用重启用无异常。

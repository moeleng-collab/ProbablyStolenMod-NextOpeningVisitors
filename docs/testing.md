# 测试说明

- 当前代码版本：`1.5.0`
- 目标游戏：《Probably Stolen》`0.46D`
- 当前状态：纯规则、构建和官方扫描已通过；真实游戏内验收未执行

## 1. 测试分层

| 层级 | 目的 | 能否证明游戏内完整正确 |
| --- | --- | --- |
| 纯规则测试 | 验证调度、冷却、文案、预测公式、报价状态与本地化 | 否 |
| 编译 | 验证源码与当前游戏引用可构建 | 否 |
| 官方扫描 | 检查程序集能力与加载器拒绝项 | 否 |
| 加载检查 | 验证发现、启用、初始化和日志 | 部分 |
| 游戏内验收 | 验证真实 UI、时序、结算、存档与交互 | 是，限实际执行场景 |

任何发布都不能只依赖编译或扫描结果。

## 2. 当前自动化结果

在游戏根目录执行：

```bash
python Modding/NextOpeningVisitors/run_tests.py
python Modding/NextOpeningVisitors/build.py
python Modding/NextOpeningVisitors/run_scan.py
```

2026-10-31 当前候选代码结果：

```text

Error: <none>
Refused: False
MethodsScanned: 161
Capabilities: <none>

```

`run_tests.py` 每次重新编译 `tests/RulesTests.cs`，避免把旧测试 DLL 当作最新结果。`build.py` 必须先于扫描运行，确保扫描最新 DLL。

### 2.1 访客调度与冷却

- 九种目标 ID 可识别，`wanted4`、空 ID 和非目标 ID 不受影响；
- 延迟归一化幂等，多目标稳定置顶，空队列安全；
- 平行队列长度不一致时拒绝处理；
- 普通／免费／奥丁重复预约保留最早项，延迟队列保持对齐；
- 有待到访预约时跳过冷却，无预约目标可重置；
- 已就绪联系人和 Wild 等非目标不修改，重复重置幂等。

### 2.2 旧电话文案与本地化

- 21 个目标 key 在 11 种语言下均有非空替换；
- 冷却按钮、结果与失败文本在 11 种语言下非空；
- 中英文订单保留数量并采用下一次开店表述；
- `pt-BR`、`zh-Hans` 等别名规范化，未知语言回退英文；
- 缺少参数、非目标 key 和冷却原文保持原样。

### 2.3 交易预测纯规则

- 调查档位边界：`99／100／299／300／849／850／1199／1200／1499／1500／2499／2500`；
- 黑市、革命、下层／`LLTIGHTLIPS`、卡特尔和其他阵营修正；
- 武器、毒品、门禁卡和普通违禁品罪名映射；
- 赃物与违禁品双标签分别贡献并汇总；
- Intimidating 后 Blabbermouth 的顺序与 `Math.Round` 边界；
- 合法物品为 `+0`，证据豁免客户全部贡献为 0；
- 输入模型在预测后保持不变。

这些断言不验证真实 `GetSellableItem()` 集合、子物品交易行为或实际 UI 刷新。

### 2.4 夜间预测纯规则

- 三种收尾人等级按“百分比整数转换后固定削减”计算；
- 调查 `<80` 逐项衰减 20，`80` 不衰减，结果不为负；
- `SEC_TRUSTED`、`SEC_PRIORITY`、`SEC_WATCHLIST`、`UL_PETITION` 的组合、优先级与取整；
- 次日调查截断到 100 并产生上限警示结果；
- 同一真实输入只生成新结果，不执行真实服务或日结。

尚未覆盖所有声望组合的组合爆炸，也未与真实睡觉结果逐项对账。

### 2.5 自动报价与持久化纯规则

- 调查不足 100 不创建，达到 100 创建初始 1000 报价；
- 同日生成幂等，拒绝当天不重建，次日可重建；
- 成功后下一报价使用增长价格，跨天 pending 失效；
- 序列化／反序列化保留报价日、价格和每日标记；
- 读取 pending 本身不重新生成或重新定价，损坏数据安全回退；
- 现金恰好足够可接受，不足时保留报价且不扣款；
- 调查已清、跨天和无 pending 均拒绝接受；
- 重复接受不能再次成功，价格序列 `1000 → 1200 → 1440`；
- 非正价格与整数溢出被拒绝。

这些测试不直接执行 Unity 电话回调、真实 `playerCash` 写入或游戏存档文件回滚。

### 2.6 新功能本地化

- 19 类预测／服务／电话／结果文本在 11 种语言下非空；
- 参数格式化可执行，未知语言回退英文；来电正文三段互不重复，价格只出现在第二段；
- 中文、英文及其他语言的实际字体、换行、遮挡和 UI 缩放尚未渲染验收。
